# Changelog

## 0.1.0 — 2026-09-14

- Added a Chrome Manifest V3 extension with explicit active-tab evidence capture.
- Added PriceTrace, ChoiceGuard, RenewalLens, and a unified risk engine.
- Added deterministic user-facing audit reports and recommended actions.
- Released FairFlow-Bench with 60 flows, 30 controlled pairs, and 240 page states.
- Added trainable text baselines and template-disjoint ablation results.
- Added privacy, retention, accessibility, security, and failure-recovery controls.
- Added reproducible evaluation, CI, Devpost copy, demo script, and submission assets.

Known boundary: version 0.1.0 supports the controlled demo adapter and synthetic benchmark. It does not claim universal website compatibility or measured real-world accuracy.
