# FairFlow submission kit

- `DEVPOST.md` — complete project story and Built with tags.
- `DEVPOST_SHORT.md` — compact story for a smaller submission field.
- `DEMO_SCRIPT.md` — timed two-minute narration and screen sequence.
- `JUDGING_GUIDE.md` — evidence mapped to common judging criteria.
- `ASSET_CHECKLIST.md` — screenshots, video, links, and human-only checks.
- `assets/fairflow-cover.svg` — editable 1280×720 project cover.

Do not submit unchecked claims. The repository supports synthetic controlled benchmark results, not universal real-site accuracy or measured user impact.
